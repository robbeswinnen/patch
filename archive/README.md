# Archived public history

These files came from the earlier public `robbeswinnen/patch` main branch. They are preserved for ideas and comparison, but they do not represent Cloudflare Worker version 115 and are not wired into the recovered build.

`public-main-only/` contains `/clan`, `/tags`, and promotion code that was not present in the deployed bundle. `public-main-docs/` contains the earlier documentation site, including descriptions of superseded commands and behavior. Port useful pieces deliberately rather than copying them into `src/` wholesale.
